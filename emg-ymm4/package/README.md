# EMG 立ち絵プラグイン for YMM4

`.emg` ファイルを YMM4（ゆっくりムービーメーカー4）の立ち絵として読み込むプラグインです。

PSD 立ち絵と違い、**読み込んだ時点でまばたきと口パクの設定が終わっています。**
どのレイヤーが「閉じた目」でどれが「あ」の口か、といった対応付けは `.emg` の中に
入っているため、ファイルを選ぶだけで動きます。

---

## 動作環境

| | |
|---|---|
| YMM4 | v4.47 以降 |
| OS | Windows 10 バージョン 2004（10.0.19041）以降 |
| .NET | YMM4 本体に同梱されているものを使うため、別途インストール不要 |

## インストール

1. この ZIP を展開します。
2. 中の **`EmgTachiePlugin` フォルダごと**、YMM4 の
   `user\plugin\` フォルダにコピーします。

   ```
   YukkuriMovieMaker_v4\
     user\
       plugin\
         EmgTachiePlugin\      ← このフォルダごと置く
           EmgTachiePlugin.dll
           Emg.Core.dll
   ```

   YMM4 のインストール先が分からない場合は、YMM4 のショートカットを右クリック →
   「ファイルの場所を開く」で確認できます。

3. YMM4 を起動し、**設定 → プラグイン** の一覧に「EMG 立ち絵プラグイン」が
   表示されていればインストール成功です。

> **YMM4 を起動したままだと上書きできません。** 更新するときは YMM4 を終了してから
> ファイルを差し替えてください。

## アンインストール

YMM4 を終了し、`user\plugin\EmgTachiePlugin` フォルダを削除してください。

## 使い方

### 1. キャラクターに `.emg` を割り当てる

**設定 → キャラクター** で対象のキャラクターを選び、立ち絵の種類を
**「EMG 立ち絵プラグイン」** に変更します。

`.emg ファイル` 欄の参照ボタンから `.emg` を選ぶと、そのキャラクターの立ち絵になります。

この時点で、`.emg` に情報があれば**まばたきと母音の口パクは自動で有効**になります。
以降の設定項目は、自動判定がうまくいかなかったときの調整用です。

| 項目 | 説明 |
|---|---|
| **.emg ファイル** | 読み込む `.emg` のパス |
| **口パク感度** | 音量ベースで口を動かすときの感度。母音の口パクが有効なら使われません |
| **まばたき開始位置** | 最初のまばたきまでの待ち時間（秒）。`0` で自動 |
| **まばたき間隔** | まばたきの周期（秒）。`0` で自動（5〜10秒の範囲でファイルごとに決まります） |
| **まばたきレイヤー** | 目のレイヤーを手動指定。空欄なら自動 |
| **口パクレイヤー（母音）** | あ/い/う/え/お/ん の口を手動指定。空欄なら自動 |

### 2. タイムラインに立ち絵を置く

キャラクターの音声アイテムを置けば、通常の立ち絵と同じように表示されます。

立ち絵アイテムを選ぶと、次の設定ができます。

| 項目 | 説明 |
|---|---|
| **拡大率** | 表示倍率 |
| **オフセットX / Y** | 表示位置の調整 |
| **Z-Index反転** | 重なり順が前後逆になっている `.emg` の救済用（下記参照） |
| **セリフが無いときは非表示** | その区間に音声が無ければ立ち絵を隠します |
| **表示レイヤー** | その区間で表示するレイヤーを直接指定します |

### 3. 表情を切り替える

**表情アイテム**をタイムラインに置くと、その区間だけ表情を変えられます。

| 項目 | 説明 |
|---|---|
| **表情名** | `.emg` に入っている表情の名前。空欄なら `default` |
| **まばたき** | 自動 / 常に開く / 常に閉じる |
| **口パク** | 母音優先 / 音量優先 / 常に開く / 常に閉じる |
| **表示レイヤー** | その区間で表示するレイヤー。立ち絵アイテム側の指定より優先されます |

表情名は `.emg` の作りによって異なります。付属のサンプル `senti.emg` では
`default` / `happy` / `shy` / `sad` / `angry` / `smug` / `dizzy` が使えます。

### レイヤーの選び方

「表示レイヤー」「まばたきレイヤー」「口パクレイヤー」の欄では、
`.emg` に入っている画像をサムネイル付きで選べます。
テクスチャの名前が `01` `02` のような番号だけでも、絵を見て選べます。

## 困ったときは

### プラグイン一覧に出てこない

- `EmgTachiePlugin.dll` と `Emg.Core.dll` が **同じフォルダ**に入っているか確認してください。
  `Emg.Core.dll` が無いと読み込みに失敗します。
- 置き場所が `user\plugin\EmgTachiePlugin\` になっているか確認してください
  （`plugin` フォルダ直下に DLL を置くのではなく、フォルダごと入れます）。
- ZIP のブロックが原因のこともあります。展開前の ZIP を右クリック → プロパティ →
  「セキュリティ: 許可する」にチェックしてから展開し直してください。

### 体が顔の手前に描かれる／重なり順がおかしい

古い書き出しツールで作られた `.emg` には、レイヤーの重なり順が前後逆に
記録されているものがあります。立ち絵アイテムの **「Z-Index反転」** を
オンにすると直ります。

### まばたきしない

`.emg` にどのレイヤーが目なのかの情報が無い場合、安全のため**まばたきは無効**になります
（間違ったレイヤーを点滅させないためです）。
キャラクター設定の **「まばたきレイヤー」** で、開いた目 → 閉じた目 の順に指定してください。

### 口が動かない／母音に合っていない

同様に、キャラクター設定の **「口パクレイヤー（母音）」** であ/い/う/え/お/ん を指定してください。
母音が揃っていない `.emg` では、自動的に音量ベースの口パクに切り替わります。

### 立ち絵が表示されない・真っ黒になる

`.emg` ファイルのパスに問題がないか確認してください。
それでも直らない場合は、YMM4 のログに `EMG` で始まる行が出ていないか確認してください。
